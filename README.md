# PDF Compressor · AGRDB

Comprime archivos PDF hasta el tamaño máximo que necesites (por ejemplo, los 5 MB que piden muchas plataformas de postulación, licitación o correo), con la mejor calidad posible dentro de ese límite.

## Descarga

👉 **[PDF_Compressor_Flet.exe](https://github.com/agrdb/Compress/releases/latest/download/PDF_Compressor_Flet.exe)** — Windows, no requiere instalación.

## Cómo se usa

1. Abre `PDF_Compressor_Flet.exe` (la primera vez tarda unos segundos en arrancar).
2. Pulsa **Buscar…** y elige tu PDF.
3. Escribe el **tamaño máximo (MB)** y deja la **calidad inicial** en 80.
4. Pulsa **Comprimir**. El archivo comprimido se guarda junto al original.

## Cómo funciona

- Primero optimiza el PDF **sin pérdida**.
- Si aún pesa más del límite, reduce la resolución de las **imágenes** por pasos (200 → 72 dpi) hasta que quepa.
- **Textos, líneas y planos vectoriales no se modifican.**
- Si no logra reducirlo, te entrega el original sin cambios.

Ejemplo: portafolio de 9,4 MB → 3,0 MB con límite de 5 MB.
